Админка сайта

Введите пароль от админки.

Где взять ключ доступа?
  1. Откройте github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Название — «Админка сайта», срок действия — максимальный.
  3. Repository access → Only select repositories → выберите репозиторий сайта.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Нажмите Generate token, скопируйте ключ и вставьте сюда. GitHub показывает его только один раз.

Ключ никуда не отправляется, кроме GitHub. В репозитории он будет храниться только зашифрованным вашим паролем. Никому его не присылайте — ни в чат, ни в почту.

Не меньше 12 знаков. Короткий и простой пароль подберут: он будет защищать доступ к сайту.
